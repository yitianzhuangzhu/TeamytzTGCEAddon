# TeamytzTGCEAddon
注意：本mod是为整合包：《征途守望·大远征（JW1_The Great Expedition）》设计的，对于个人使用或者其它整合包需要玩家/作者自行加入合成表等。
# 介绍
该mod是由异天庄团队（TeamYTZ）设计的科技枪社区版（Techguns-CE）的拓展mod，加入了新的武器，机器。
## 安装方法
1. 确保已安装Minecraft Forge 1.12.2
2. 安装科技枪社区版（Tech Guns CE）2.1.3或更高版本
3. 将本Mod的jar文件放入游戏的mods文件夹
4. 启动游戏
## 兼容性
本Mod的兼容性可参考科技枪社区版，暂无确定的不兼容信息，有问题可以在issue上报告。
<br />
## 多人游戏支持
本Mod完全支持多人游戏，所有武器和物品都可以在服务器上正常使用。
